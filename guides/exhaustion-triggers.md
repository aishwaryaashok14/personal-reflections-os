# Exhaustion Triggers Guide

**Purpose:** Identify what specifically drains you and create real-time detection systems

**Time needed:** 20-30 minutes

---

## Common Exhaustion Triggers

Based on patterns from many people, here are the most common exhaustion sources. Check which ones resonate with YOU based on your Q3 answers and patterns.

### 1. Volume Without Integration
**What it looks like:**
- 10+ things in "active" status
- Switching between many different projects in one day
- Each pursuit is siloed, none connect
- Browser tabs/apps open for different identities

**Why it exhausts:**
Not the activities - it's managing too many separate streams without integration

---

### 2. Everything Has to Count Publicly
**What it looks like:**
- "Should I post this?"
- "Could this become a workshop/product?"
- Can't try something without it becoming content
- No private space to just BE

**Why it exhausts:**
Creation becomes performance. You're always on stage.

**Your trigger?** [ ] Yes [ ] No

---

### 3. The Comparison Loop
**What it looks like:**
- Scroll social media → see others' wins → feel behind
- Check metrics/numbers → "should be more"
- "I'm doing so much but the world is racing ahead"

**Why it exhausts:**
Measuring present reality against future ideal AND others' highlight reels simultaneously

**Your trigger?** [ ] Yes [ ] No

---

### 4. One-Sided Relationship Labor
**What it looks like:**
- Someone asks for advice/time/connections
- You show up, give value
- They disappear until next ask
- Performative friendships, drama without resolution

**Why it exhausts:**
Social energy is finite. Takers drain without refilling.

**Your trigger?** [ ] Yes [ ] No

---

### 5. Stuck in One Mode Too Long
**What it looks like:**
- 5 consecutive days of just work
- OR: 3 days of intense creation with no restoration
- OR: Full week of social performance without solitude

**Why it exhausts:**
Your system needs mode variety. Any single mode for too long = suffocation.

**Your trigger?** [ ] Yes [ ] No

---

### 6. Physical Stagnation
**What it looks like:**
- Multiple days at desk without walking
- Same room, same city, same routine
- Body is still for too long

**Why it exhausts:**
You're a kinesthetic processor (if this is true for you). Movement = how brain works.

**Your trigger?** [ ] Yes [ ] No

---

### 7. Work Presence Constraints
**What it looks like:**
- Required office presence when remote would work better
- Fixed schedule when creative energy peaks at different times
- Location-bound when you need movement freedom

**Why it exhausts:**
Structure fights your operating system. Need flexibility to integrate identities.

**Your trigger?** [ ] Yes [ ] No

---

### 8. Guilt When Not Producing
**What it looks like:**
- Resting → "Should be working on something"
- Walking → "This isn't productive"
- Family time → "Could've used this time to create"

**Why it exhausts:**
Can't recharge because restoration feels like failure. Battery never refills.

**Your trigger?** [ ] Yes [ ] No

### The Trigger Question Framework

**When feeling exhausted, ask in this order:**

**1. VOLUME CHECK**
"How many things am I actively trying to do right now?"
→ If >5: Move 2-3 to Someday immediately

**2. PUBLIC PRESSURE CHECK**
"Does this have to count/be seen?"
→ If yes to everything: Schedule 3 hours private creation

**3. COMPARISON CHECK**
"Am I measuring against someone/something?"
→ If yes: Close social media, reconnect with MY goals

**4. RECIPROCITY CHECK**
"Have I given more than received this week?"
→ If yes: Decline next request, prioritize grounding relationships

**5. MODE CHECK**
"How long in this mode?"
→ If >2-3 days: Force a switch

**6. MOVEMENT CHECK**
"When did I last walk/move/change place?"
→ If >24 hours: Walk immediately, 30+ min, no phone

**7. WORK STRUCTURE CHECK**
"Is constraint external (work) or internal (my choices)?"
→ If external: Document what flexibility needed
→ If internal: I have more control than I think

**8. REST GUILT CHECK**
"Am I judging myself for not producing?"
→ If yes: Read Permission Statements

## Prevention > Response

**Better than reacting to exhaustion:** Build prevention into your operating system

### Daily Prevention:
- [ ] Morning restoration time (before depletion)
- [ ] Movement/place-change built in
- [ ] Clear work boundaries

### Weekly Prevention:
- [ ] 50% private creation (not all public)
- [ ] Active queue pruning (keep at 3-5)
- [ ] Mode variety (not stuck too long)
- [ ] Reciprocal-only social time

### Monthly Prevention:
- [ ] Public visibility budget (1-2 moments max)
- [ ] Say no quota (2-3 misaligned opportunities)
- [ ] Social media breaks (3-day detox)
- [ ] Quarterly Someday List review
