**Created:** January 2026
**Status:** Ready for open-source release
**License:** MIT

## What We Built

A complete, open-source framework for self-discovery and personal systems design that transforms overwhelming ambition into sustainable living.

### Core Problem It Solves

People feel:
- "I'm doing so much but feel behind"
- "Too many goals, can't focus on anything"
- "Don't know why I'm exhausted despite loving what I do"
- "Guilty when not producing"
- "Like I should be one thing but want to be many things"

### What This Framework Provides

**1. Self-Knowledge**
- Personality architecture mapping (how you're wired)
- Energy system understanding (what fills/drains you)
- Exhaustion trigger identification (what specifically depletes you)

**2. Sustainable Systems**
- Three-track system (Anchor, Exploration, Restoration)
- Active Queue management (3-5 items max, not 20+)
- Boundaries and practices aligned with your nature

**3. Implementation Support**
- 90-day rollout plan
- Daily/weekly/monthly tracking tools
- Emergency protocols for overwhelm

## Two Ways to Use It

### 1. **Interactive Skill** (Hybrid Approach - Recommended)

**For Claude Code CLI users:**
```bash
/personal-os         # Full interactive session
/personal-os quick   # 30-minute version
/personal-os analyze # Analyze existing thought dump
/personal-os resume  # Continue previous session
```

**Experience:**
- Conversational guidance (like a coach)
- Real-time analysis as you answer
- Adaptive to your pace
- Generates complete document at end
- Can pause/resume anytime

**Time:** 2-3 hours interactive, generates everything for you

---

### 2. **Self-Guided Framework** (Traditional Approach)

**For anyone:**
- Download templates
- Complete thought dump
- Answer questionnaire
- Use analysis guides
- Design operating system
- Implement over 90 days

**Experience:**
- Work at your own pace
- Spread over multiple days
- Print and use offline
- Full control

**Time:** 3-4 hours upfront + ongoing practice

## Core Principles

1. **Self-knowledge over external advice** - Your OS matches YOUR wiring
2. **Integration over balance** - All parts coexist, not separated
3. **Sustainable over optimal** - Good enough you maintain > perfect you abandon
4. **Descriptive over prescriptive** - How you ACTUALLY work
5. **Private space matters** - 50% of work should be unseen
6. **Capacity over ambition** - Honor actual bandwidth
7. **Energy over time** - Manage what fills/drains you
